# FORM rank audio — announcer edition

Current cues combine Kenney CC0 recorded game-development impacts with processed synthetic English rank announcements. See ANNOUNCER.md for provenance and build details and Kenney-License.txt for the source licence. These are not Brawl Stars recordings or an imitation of a specific actor.

Every rank has its own rendered stereo file. Voice is mixed into the file, so replay, stop, mute and saved volume affect both sound and voice together. Versioned URLs avoid playing the previous cached mix.
