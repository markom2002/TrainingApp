# FORM visual assets

These four images were generated with the imagegen skill for this application:

- `gym.webp`: gym/training background used by dashboard, login and focus panels.
- `equipment.webp`: equipment still life used by workout, profile and progress headers.
- `male.webp`: graphite athletic sculpture atlas, front view on the left and back on the right.
- `female.webp`: matching female sculpture atlas, front view on the left and back on the right.

The sculptures are decorative training references, not medical anatomy diagrams. Men/Women presentation does not restrict the exercise catalog. Assets live in this repository and are served locally; no external image host is needed.
