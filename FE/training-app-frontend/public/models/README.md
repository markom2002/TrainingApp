# FORM athlete

`athlete-v3.glb` is a locally served, modified CC0 adult male base mesh. Modified for this app with neutral matte materials, compression shorts, weighted muscle volume, sculpted lat/scapular/trapezius contours, abdominal and pectoral divisions, anatomical vertex shading and recomputed normals. Animation, equipment and muscle highlighting are implemented locally in the app; no remote viewer is embedded.

Source: [Innerscene male base mesh, adapted from MakeHuman CC0 assets](https://www.innerscene.com/tools/library/3d-parts/male-base-mesh-3d-person-rigged-a-pose-380e6d89).
License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Retrieved 2026-11-14. The publisher states that redistribution and modification are permitted.

Original download: https://files.innerscene.com/library/male-base-mesh-3d-person-rigged-a-pose-380e6d89/038f3a526b2fc3efd012/male-base-mesh-base_male.glb

Rebuild: node scripts/Prepare-Athlete.mjs <original-GLB-path> from the repository root. Muscle highlighting is smooth vertex colour, not a clinical activation simulation.
